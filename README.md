# Writing Buddy
_a desktop app for writers_

**Updates:** <br>
Functional. <br>
Entered refinement stage. <br>
Expect changes in UI (layout, colors, etc)

## Goal
The goal is to help **writer focus**, with a word counter and other minor tools to make the writing process more efficient.

## Features
### Main
- **Input Box** - Allows users to enter and edit text. <br>
- **Word Counter** - Counts words written on textarea box. <br>
- **Copy text Button** — Copies all written content to the clipboard with a single click. <br>
- **Word Count Goal** - Notifies when the word count goal has been achieved.

### Extra
- **Light/Dark Mode** - Allows users to toggle light or dark mode for better user experience <br>
- **Work title change** - Change title of work. At the moment this is only visual. <br>
- **Word Counter percent** - Percentage of completion below word count once the goal is hidden. <br>
- **Textarea Size** - User can choose the size of the writing font.<br>
- **Textarea Weight** -  User can choose the weight of the writing font.<br>
- **Animated Companion** - Still in development, but it moves.<br>
